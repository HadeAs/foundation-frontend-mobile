# 南瑞物流 App 业务接口清单

> 版本：1.0.0 ｜ 整理日期：2026-09-08
>
> 根据已确认业务 SPEC 和首页 15 个功能整理，供后端定义具体接口。本文仅列中文接口名称及职责，不定义 URL、请求方式或字段结构，也不表示相关接口已经实现。

## 使用说明

- 按首页分类和菜单顺序列出所需接口能力；同名接口可复用，最终拆分或合并由后端确定。
- 查询负责识别对象、返回页面所需信息及业务校验；正式提交时仍须重新校验当前关系和状态。
- MES、SAP、LES、WMS 的跨系统处理由后端统一组织，App 只调用业务查询和提交接口，不逐步调用外部系统。
- 登录、个人信息、版本更新等不属于本次首页 15 个功能，未纳入本清单。

## 一、常规作业

### 1. 板件扫码绑箱

| 接口名称 | 简要描述 |
| --- | --- |
| 查询料箱及已绑定板件 | 扫描箱码后查询料箱信息、已绑定板件及数量，用于提示是否一键解绑和展示已有明细。 |
| 查询板件信息 | 按板件唯一码查询板件、物料及订单信息，校验是否可绑箱；查询不直接建立绑定。 |
| 获取拼板板件 | 根据当前已绑定及本次待绑定板件，查询可一并装箱的拼板板件，供前端去重后直接加入待绑定列表。 |
| 按唯一码批量绑箱 | 将本次待绑定板件批量绑定至料箱；不重复提交已有绑定，不限制同一订单。 |
| 全部解绑箱内板件 | 解除料箱内全部板件绑定，用于扫描非空箱后的确认操作，保留历史记录。 |

### 2. 板件快捷绑箱

| 接口名称 | 简要描述 |
| --- | --- |
| 查询料箱及已绑定板件 | 判断料箱是否为空；非空箱须先一键解绑才能继续快捷绑箱。 |
| 全部解绑箱内板件 | 用户确认后解除非空箱内全部板件绑定。 |
| 查询板件信息 | 扫描板件唯一码后取得对应订单号，供快捷绑箱使用；订单号也可手动填写。 |
| 按订单数量绑箱 | 根据选定料箱、订单及数量完成快捷绑箱，校验订单、数量及料箱当前状态。 |

### 3. 板件解绑

| 接口名称 | 简要描述 |
| --- | --- |
| 查询料箱及已绑定板件 | 扫描料箱后取得全部已绑定板件，供查看、勾选和扫码匹配。 |
| 解绑所选板件 | 解除所选一条或多条板件与料箱的关系，保留对象及历史记录。 |
| 全部解绑箱内板件 | 一次解除当前料箱内全部板件绑定。 |

### 4. 装车

| 接口名称 | 简要描述 |
| --- | --- |
| 查询载具库位信息 | 扫描载具上的库位号，查询该库位及所属载具，并校验是否可装载。 |
| 查询装车料箱信息 | 扫描箱码后识别料箱，校验当前装载关系及是否允许装车。 |
| 批量装车 | 将本次录入的多组料箱与载具库位配对批量绑定，校验重复及关系冲突。 |

### 5. 卸车

| 接口名称 | 简要描述 |
| --- | --- |
| 查询载具装载明细 | 扫描载具后查询其全部库位及已装载料箱，供查看、勾选和扫码匹配。 |
| 卸载所选料箱 | 解除选中一箱或多箱与载具库位的绑定，保留历史记录。 |
| 全部卸载料箱 | 解除当前载具全部库位上的料箱绑定。 |

### 6. 位置绑定

| 接口名称 | 简要描述 |
| --- | --- |
| 查询库位及绑定容器 | 扫描库位后查询库位信息和当前绑定的载具或料箱，判断能否继续绑定新容器。 |
| 查询待绑定容器 | 库位为空时，识别扫描的载具或料箱，查询容器信息并校验是否允许绑定。 |
| 绑定容器到库位 | 将载具或料箱绑定至目标库位，重新校验占用状态，并按后端规则触发后续流程。 |
| 解绑库位容器 | 解除库位与当前容器的绑定关系，保留历史追溯记录。 |

### 7. 缴库申请

| 接口名称 | 简要描述 |
| --- | --- |
| 查询缴库申请对象 | 扫描载具或料箱，查询对象、关联料箱和物料；仅查询展示，不立即申请，无可处理物料时不能提交。 |
| 查询箱内物料明细 | 点击关联料箱时查询其物料明细，用于只读弹窗展示。 |
| 提交缴库申请 | 整批处理对象下物料，依次执行 MES 物料校验、SAP 缴库单申请、WMS 待上架清单新增；前一步成功后才能继续，返回申请结果及缴库单号。 |

## 二、库房作业

### 8. 物料接收

| 接口名称 | 简要描述 |
| --- | --- |
| 查询对象接收任务 | 按箱码或载具码查询当前接收任务及关联明细；无任务时明确告知该对象无接收任务。 |
| 查询箱内物料明细 | 点击载具内料箱时查询箱内物料，供弹窗展示。 |
| 确认物料接收 | 完成当前对象的接收操作并记录接收人、时间及结果，不自动执行卸车或板件解绑。 |
| 清空对象 WMS 历史绑定 | 按当前接收对象清理对应 WMS 历史绑定关系，返回处理结果；关系清理不删除历史追溯记录。 |

### 9. 待接收物料清单

| 接口名称 | 简要描述 |
| --- | --- |
| 分页查询待接收物料清单 | 按载具号、库位号筛选当前待接收任务，分页提供任务号、载具、库位及创建时间等展示信息，支持滚动加载。 |

### 10. 成品发货

| 接口名称 | 简要描述 |
| --- | --- |
| 查询成品发货对象 | 按位置、料车或料箱识别发货对象及全部关联料箱、物料；扫描位置时按实际绑定容器识别，无容器或无物料时不能提交。 |
| 查询箱内物料明细 | 点击发货对象下的料箱，查询物料供只读展示，不提供部分选择。 |
| 提交成品发货 | 依次清空 LES 历史绑定、新增本次 LES 绑定、清空对应 WMS 绑定，返回发货结果及相关业务单号；保留发货和绑定历史记录。 |
| 查询物流发起信息及可选目标位置 | 料车发货成功后选择创建物流任务时，复用现有物流查询能力，取得该料车起始位置及可选目标位置。 |
| 创建物流任务 | 复用现有任务创建能力，员工选择目标位置后创建任务；后续取消创建或创建失败不撤销已完成发货。 |

## 三、物流作业

### 11. 发起物流任务

| 接口名称 | 简要描述 |
| --- | --- |
| 查询物流发起信息及可选目标位置 | 扫描载具或起始位置，识别关联容器、当前位置及允许选择的目标位置；提供楼层、区域、库位层级信息，规则和任务类型由后端决定。 |
| 创建物流任务 | 按确认的运输对象、起始位置及目标位置创建任务，返回创建结果、任务编号及当前状态。 |

### 12. 取消物流任务

| 接口名称 | 简要描述 |
| --- | --- |
| 查询可取消物流任务 | 仅查询当前可取消的任务，支持容器码、AGV 编号或名称搜索，提供任务编号、AGV、关联容器、起始位置、目标位置、状态、发起方式及时间。 |
| 取消物流任务 | 对员工确认的任务执行取消，再次校验当前状态，返回成功结果或不可取消原因，并记录取消操作。 |

### 13. 呼叫空载具

| 接口名称 | 简要描述 |
| --- | --- |
| 查询空载具可选起始位置 | 扫描目标位置后查询可选起始位置及各位置上的空载具，提供三级位置层级；一个起始位置最多对应一个空载具。 |
| 确认呼叫空载具 | 根据员工最终选择的起始位置及扫描的目标位置，校验对应空载具并创建物流任务，返回呼叫结果。 |

### 14. 交通管制

| 接口名称 | 简要描述 |
| --- | --- |
| 查询交管区域 | 按区域编号或名称及状态查询区域，展示编号、名称、空闲或占用状态、最后操作人及时间。 |
| 锁定交管区域 | 对当前空闲区域执行锁定，返回更新后的状态与操作信息。 |
| 释放交管区域 | 对当前占用区域执行释放，返回更新后的状态与操作信息。 |

### 15. 缴库发起

| 接口名称 | 简要描述 |
| --- | --- |
| 查询缴库发起信息及推荐地点 | 扫描载具或位置，查询来源对象及关联明细，校验发起条件，提供推荐目标及可选地点层级；无目标或条件不满足均按扫描失败返回具体原因。 |
| 查询箱内物料明细 | 点击关联料箱时查询物料，用于只读弹窗展示。 |
| 创建缴库物流任务 | 按员工确认的推荐或可选目标地点创建到库房的物流任务，返回创建结果及任务编号。 |

## 四、复用与边界说明

- **箱内板件查询与全部解绑**：板件扫码绑箱、板件快捷绑箱、板件解绑共用对应能力；箱内物料弹窗查询也可按业务数据来源复用。
- **板件信息查询**：扫码绑箱与快捷绑箱共用，须支持取得对应订单信息。
- **物流任务创建**：成品发货后的可选创建复用“发起物流任务”；缴库物流和空载具呼叫能否共用具体接口由后端决定，但各自规则需保留。
- **整批与所选操作**：所选/全部解绑、所选/全部卸车可由同一接口承载；列表分开列出是为了覆盖业务能力。交管锁定/释放也可合并为状态修改接口。
- **外部系统编排**：成品发货、缴库申请各由一次业务提交触发完整处理，不要求 App 分别调用 LES、MES、SAP、WMS。失败后再次点击为新的完整提交请求，不按上次进度接续。
- **前端本地操作**：清空页面、删除未提交记录、物料/箱码匹配已加载列表并勾选、三级级联切换与去重无需单独接口。候选位置层级可随扫描查询一次提供。
- **记录与错误**：业务接口应记录操作人、时间、终端/工位、对象、关系变更、结果和相关业务单号，并给出可直接展示的失败原因；不因关系清理删除追溯记录。本期不额外增加操作记录页面或查询接口。
- **本清单不增加业务范围**：不新增审批、离线补传、AGV 调度执行及库存入账接口。是否拆分箱/载具识别、明细查询、跨系统内部服务，由后端结合现有能力确定。
