# 南瑞物流 App 业务接口清单

> 版本：1.0.30 ｜ 最后更新：2026-10-12
>
> 根据已确认业务SPEC和首页18个功能整理，供后端定义具体接口。本文只列中文接口名称及职责。最新OpenAPI已补齐直接关系接口；正式应用已接18个菜单，包含料箱绑车及料箱解绑，前端接入不代表后端部署或联调完成。

## 使用说明

- 按首页分类和菜单顺序列出所需接口能力；同名接口可复用，除已明确要求独立的接口外，最终拆分或合并由后端确定。
- 查询负责识别对象、返回页面所需信息及业务校验；正式提交时仍须重新校验当前关系和状态。
- MES、SAP、LES、WMS 的跨系统处理由后端统一组织，App 只调用业务查询和提交接口，不逐步调用外部系统。
- 登录、个人信息、版本更新等不属于本次首页 18 个功能，未纳入本清单。

## 一、常规作业

### 1. 板件扫码绑箱

| 接口名称 | 简要描述 |
| --- | --- |
| 查询料箱及已绑定板件 | 扫描箱码后查询料箱信息、已绑定板件及数量，用于提示是否一键解绑和展示已有明细。 |
| 查询板件信息 | 按板件唯一码查询板件、物料及订单信息，校验是否可绑箱；查询不直接建立绑定。 |
| 获取拼板板件 | 仅根据本次待绑定板件查询完整拼板候选，不传箱信息、不以箱内已有绑定作为依据；供前端去重后直接加入待绑定列表。 |
| 按唯一码批量绑箱 | 仅提交本次待绑定板件；混料先返回未写入的提醒及确认凭据，人员继续后原样带凭据再次提交，最终回执才表示已绑定。混装仅用于缴库，不参与生产配送。 |
| 全部解绑箱内板件 | 解除料箱内全部板件绑定，用于扫描非空箱后的确认操作，保留历史记录。 |

### 2. 板件快捷绑箱

| 接口名称 | 简要描述 |
| --- | --- |
| 查询料箱及已绑定板件 | 返回实际内容、完整关系、已有数量及资格；同数量方式可追加，唯一码方式须先解绑才能切换。没有板件关系不代表实际空载。 |
| 全部解绑箱内板件 | 用户确认后解除唯一码方式已有绑定，返回最新版本；随后重新查询实际内容和资格，正常成功保留箱子继续作业。 |
| 查询板件信息 | 由实际代表板件唯一码取得订单、物料及可用批次，订单只读回显；不建立该代表码的逐件绑定，不允许手填或拼造代表码。 |
| 按订单数量绑箱 | 按实际代表码、对应订单及数量绑箱并重新解析/校验；混料先返回未写入的原因及凭据，人员继续以新UUID和冻结输入回传凭据，完成回执才表示成功。 |

### 3. 板件解绑

| 接口名称 | 简要描述 |
| --- | --- |
| 查询料箱及已绑定板件 | 一次取得完整关系、逐行批次、汇总、版本、实际内容及操作资格，供查看、勾选和纯前端唯一码匹配；无板件关系不等于实际空载。 |
| 解绑所选板件 | 按所选关系原ID/版本整行解除，数量行不部分减量；校验箱版本，返回原请求标识、解除条数、最新箱版本和剩余数量，保留历史。 |
| 全部解绑箱内板件 | 按箱及版本解除全部板件关系，不受勾选或所选1000条上限影响；返回完整回执与剩余0件，不据此推断治具箱实际空载。 |

### 4. 装车

| 接口名称 | 简要描述 |
| --- | --- |
| 查询载具库位信息 | 查询真实载具库位、所属载具、占用箱、版本及资格；不虚构装载位，不与固定业务位置或料箱直接绑定混用。 |
| 查询装车料箱信息 | 识别料箱、版本及可用实际内容摘要，校验已有装载与直接关系互斥；不允许时提供原因，查询不自动解除关系。 |
| 批量装车 | 原子校验并绑定本次完整配对，返回关联原请求的处理编号、时间和实际装载条数；一项失败整批不写入，未知结果支持原UUID及原输入手动重试。 |

### 5. 卸车

| 接口名称 | 简要描述 |
| --- | --- |
| 查询料车库位及绑定料箱 | 返回完整一致的真实库位、装载关系ID/版本、料箱、实际内容与物料明细及汇总，供纯前端箱码匹配；物料名称/单位/批次可缺省，零条板件不等于实际空载。与直接绑定查询不同，不分页或截断。 |
| 卸载所选料箱 | 按载具聚合版本及最多1000条关系原ID/版本整批解除库位装箱关系，保留箱内板件与历史；返回本次UUID、处理编号/时间及解除关系数，未知结果支持原入参/UUID手动重试。 |
| 全部卸载料箱 | 按载具及版本解除全部库位装箱关系，不提交勾选项，不受所选1000条上限影响；返回完整关联回执，不解除独立料车—料箱直接关系或箱内板件。 |

### 6. 料箱绑车

| 接口名称 | 简要描述 |
| --- | --- |
| 查询料车及直接绑定料箱 | 扫描后由后端识别料车，完整一致返回编号、显示名、聚合版本及全部直接关系，不受提交1000箱上限影响；显示名缺失由后端回退编号，不混入库位装载。已有绑定时询问一键解绑，否后才展示旧箱并允许追加。 |
| 一键解绑料车下料箱 | 与料箱解绑共用；按当前料车快照解除全部直接关系，返回原请求标识、空列表及最新料车版本，供无需重扫继续绑箱；不执行卸车或板件解绑，保留历史，未知结果可原入参/UUID手动重试。 |
| 查询待绑定料箱及所属料车 | 返回目标料车/料箱摘要、旧关系及所属车（无关系显式null）、有效操作资格和原因；所属其他车时先确认再加入，查询不写入。与库位装载互斥，不隐式卸车。 |
| 批量绑定或换绑料箱 | 仅提交最多1000个本次待绑定箱及原关系快照、版本、换绑确认，不重复提交已有箱；后端整批原子处理并返回完整当前直接关系快照及更新版本，须保留全部原有关系与新增/换绑箱，不返回部分成功。未知结果支持原UUID/原入参手动重试。 |

### 7. 料箱解绑

| 接口名称 | 简要描述 |
| --- | --- |
| 查询料车及直接绑定料箱 | 完整一致返回料车/料箱显示名、版本及直接关系原文本标识/版本，供展示和纯前端箱码匹配；不分页或截断，不混入卸车库位关系，不补造实际内容或物料字段。 |
| 解绑勾选料箱 | 按料车聚合版本及最多1000条关系/箱凭据原子解除，保留箱内板件及历史；返回原UUID、新料车版本与全部未选关系，未选关系和箱版本保持原样。异常回执不得视为完成，未知结果可原入参/UUID手动重试。 |
| 一键解绑料车下料箱 | 解除当前料车全部直接关系，不提交勾选项、不受所选1000条上限影响；回执返回原UUID、最新料车版本及空列表，不清理库位装载、板件或历史，未知结果可原请求手动重试。 |

### 8. 位置绑定

| 接口名称 | 简要描述 |
| --- | --- |
| 查询库位及绑定容器 | 完整返回库位、占用容器、双方版本、绑定资格、全部阻塞任务和独立解绑资格；无任务也须检查实物及业务保护。取消核实后复用查询刷新最新版本。 |
| 查询待绑定容器 | 空闲库位识别扫描的载具或料箱及自身资格；规范编码由后端识别，自身可用不等于与目标库位兼容。 |
| 绑定容器到库位 | 原子复核占用、双方版本与规则，建立关系并返回完整关联回执；绑定完成不表示搬运完成，不修改容器内部关系。 |
| 取消物流任务（复用） | 只取消当前位置查询返回的允许取消阻塞任务，带任务版本及自动生成的位置解绑上下文；受理不代表最终取消，保留独立取消权限及占用关系自动任务抑制。 |
| 查询物流任务取消结果（复用） | 以原任务标识及取消请求标识核实结果；受理或未知不重新取消，失败展示原因。最终取消仍须重查位置、版本和实物解绑资格。 |
| 解绑库位容器 | 无阻塞且后端实物资格允许后，人员再次确认，以新请求及最新双方版本解除原占用关系；再次原子校验，不能自动取消任务或清空内部装载/板件/历史数据。 |

### 9. 缴库申请

| 接口名称 | 简要描述 |
| --- | --- |
| 查询缴库申请对象 | 唯一识别载具或料箱，完整一致返回对象版本、实际内容、全部料箱/物料及数量汇总和资格；名称、单位、批次可缺省，不以零条板件推定空载。仅查询，不立即申请或分页截断。 |
| 查询箱内物料明细 | 按缴库申请用途返回完整箱物料及后端决定的来源；只读展示可选名称、单位与文本批次，不覆盖原申请对象版本。 |
| 提交缴库申请 | 按整个解析对象及版本编排MES校验、SAP申请、WMS待上架新增，完整完成后返回原请求标识、申请编号、SAP单号及时间；不代表最终入库。未知结果支持同标识/完整输入手动重试，不由App接续外部步骤。 |

## 二、库房作业

### 10. 物料接收

| 接口名称 | 简要描述 |
| --- | --- |
| 查询对象接收任务 | 识别箱或车，完整返回成功送达运输的固定箱/物料范围、整批接收进度、任务版本与对象资格；不按当前装载推算。重扫优先新任务，无新任务时允许按已知运输标识重查本次范围供WMS清理，无范围明确告知。 |
| 查询箱内物料明细 | 按接收用途查询本次送达料箱的完整物料明细及后端决定的来源，供只读弹窗展示可选名称、单位和文本批次，不覆盖提交用任务版本。 |
| 确认物料接收 | 按任务最新版本及扫描对象确认单箱或整车剩余箱，保留先前记录；可填本次备注。回执关联原请求、任务、对象及更新任务版本，影响数为新增接收箱数。未知结果原请求手动重试，不卸车、不解绑、不表示库存入账。 |
| 清空对象 WMS 历史绑定 | 独立于接收资格，按固定运输/对象范围清理WMS记录，接收前后均可；保留LES关系及历史。通用回执影响数可为0、不含新任务版本，后续操作重新查询，不推算版本。 |

### 11. 待接收物料清单

| 接口名称 | 简要描述 |
| --- | --- |
| 分页查询待接收物料清单 | 按载具号、库位号精确筛选已送达运输的待接收投影，分页提供任务号、对象、可选库位、创建时间和整批接收状态/箱数；部分接收保留、全范围完成后退出。只读查询、不生成接收批次、不按当前装载推算；原文本任务身份及版本完整，支持刷新和触底加载。 |

### 12. 成品发货

| 接口名称 | 简要描述 |
| --- | --- |
| 查询成品发货对象 | 识别位置、料车或料箱，保留原扫描凭据及实际容器/版本，一致返回全部关联箱及WMS本次完整发料内容；无完整明细明确失败，不以旧LES冒充。展示可选物料字段/文本批次及独立实际内容，无容器或无物料不能提交。 |
| 查询箱内物料明细 | 按发货用途从WMS取得该箱本次完整板件明细，供只读弹窗展示可选名称、单位和文本批次；不提供部分选择，不替换发货对象提交版本。 |
| 提交成品发货 | 冻结并复核本次WMS行范围后，关闭旧LES有效绑定、按WMS重建并更新箱/料车版本，再清理对应WMS；保留历史，不建发货/库存台账。完整回执关联原请求、发货编号及更新对象，未知结果原UUID手动重试，外部失败不由App回滚或重建；后续运输独立创建。 |
| 查询物流发起信息及可选目标位置 | 料车发货成功后选择创建物流任务时，复用现有物流查询能力，取得该料车起始位置及可选目标位置。 |
| 创建物流任务 | 复用现有任务创建能力，员工选择目标位置后创建任务；后续取消创建或创建失败不撤销已完成发货。 |

## 三、物流作业

### 13. 发起物流任务

| 接口名称 | 简要描述 |
| --- | --- |
| 查询物流发起信息及可选目标位置 | 扫描载具、料箱或起始位置，由后端唯一识别实际运输对象、起始位置及品牌；固定GENERAL，返回完整三级候选及资格，不默认品牌或将位置箱改成整车。实际内容独立返回，未确认不视为空载，候选不分页/截断。 |
| 创建物流任务 | 回传查询对象/聚合版本、品牌/GENERAL、起始及员工选择的目标，后端复核并返回原UUID、任务身份/版本、实际起止及标准运输状态；创建不代表执行完成。未知结果手动复用原UUID及内容，不自动创建新意图；成品发货来源只在指定模式携带关联单号。 |
| 创建回库物流任务 | 复用创建能力的回线边库模式，按当前识别载具/版本/起始及配置由后端分配真实兼容目标，不传手选目标或本地推定资格。完整回执校验与指定任务一致，未知结果原请求手动重试；前端启用范围保持已确认载具场景，生产目标配置需联调确认。 |

### 14. 取消物流任务

| 接口名称 | 简要描述 |
| --- | --- |
| 查询可取消物流任务 | 后端按可取消规则及容器码/AGV关键词分页筛选，提供完整任务文本身份/标准版本、GENERAL、品牌、容器、真实起止及标准运输状态/名称、方式/时间；AGV可缺省。前端不按状态再次筛除，异常页不替换有效列表。 |
| 取消物流任务 | 按员工二次确认的任务ID、标准任务版本与已保存的UUID取消，普通取消不带位置解绑上下文或容器版本。即时回执只表达受理/最终取消并关联原请求及处理时间；受理不等于成功，取消不代表实物结算/位置解绑。 |
| 查询本次物流任务取消结果 | 用原任务ID/取消UUID核实受理、最终取消、失败或未知，即使任务已退出列表仍可查询；必返有效处理时间，失败/未知须完整原因。已受理可见时轮询，异常/未知停止并手动查询，不自动重发取消或更换UUID。 |

### 15. 呼叫空载具

| 接口名称 | 简要描述 |
| --- | --- |
| 查询空载具可选起始位置 | 只按目标位置查询后端认可的完整起点及关联载具，返回完整三级层级、编码和版本，默认首项；不分页/截断或前端推定空载。实际内容/可信当前位置可缺省，有值须有效且当前位置与候选一致，空列表保留目标并禁止提交。 |
| 确认呼叫空载具 | 按最终起止位置、关联载具和原版本/UUID复核并创建任务，返回完整关联任务身份/标准版本、容器/位置及运输状态/时间；已创建不代表到达。未知结果支持原UUID/完整内容手动重试，明确拒绝或确认更换起点/目标才使用新意图，不自动重发。 |

### 16. 交通管制

| 接口名称 | 简要描述 |
| --- | --- |
| 查询交管区域 | 按编号/名称及空闲/占用状态分页查询，返回完整区域身份、标准状态版本及可选有效操作历史，缺省历史显示占位。按后端排序展示，异常分页/字段不覆盖原列表，不增加前端资格过滤。 |
| 锁定交管区域 | 二次确认后提交区域原版本和本次UUID，后端复核空闲状态与权限；返回同一区域、递增版本及占用状态快照，非异步受理回执。未知结果可原UUID/入参手动重试，成功更新卡片，不解除其他业务关系。 |
| 释放交管区域 | 二次确认后提交区域原版本和本次UUID，后端复核占用状态与权限；返回同一区域、递增版本及空闲状态快照。未知结果可原UUID/入参手动重试，明确拒绝或改区域/状态版本后新意图；无独立结果查询接口。 |

### 17. 缴库发起

| 接口名称 | 简要描述 |
| --- | --- |
| 查询缴库发起信息及推荐地点 | 扫描载具或位置，完整一致返回真实载具、聚合版本、箱/物料汇总及完整唯一推荐候选，固定GENERAL；名称/单位/批次可缺省，不推定实际空载。位置关联料箱、无目标或条件不满足按扫描失败提供原因，不展示部分结果。 |
| 查询箱内物料明细 | 按缴库发起用途查询完整只读物料，由后端决定来源；可选文本批次/名称/单位不阻断展示，详情新版本不覆盖原提交快照。 |
| 创建缴库物流任务 | 按原扫描身份、真实载具/版本及最终目标创建到库房任务，返回原UUID及完整任务身份/标准版本、容器/起止及运输状态/时间；已创建不代表到达或入库，不再次发起MES/SAP/WMS申请。未知结果支持原UUID/完整输入手动重试。 |

### 18. 手动叫料

| 接口名称 | 简要描述 |
| --- | --- |

## 四、复用与边界说明

- **箱内板件查询与全部解绑**：板件扫码绑箱、板件快捷绑箱、板件解绑共用对应能力；箱内物料弹窗查询也可按业务数据来源复用。
- **板件信息查询**：扫码绑箱与快捷绑箱共用，须支持取得对应订单信息。
- **物流任务创建**：成品发货后的可选创建复用“发起物流任务”；缴库物流和空载具呼叫能否共用具体接口由后端决定，但各自规则需保留。
- **整批与所选操作**：所选/全部解绑、所选/全部卸车可由同一接口承载；列表分开列出是为了覆盖业务能力。交管锁定/释放也可合并为状态修改接口。
- **独立容器关系**：料箱绑车/料箱解绑维护料车—料箱直接关系；装车/卸车维护料箱—料车库位关系，两类有效关系互斥。直接关系查询和库位装载查询不同，不合并结果。换绑只在确认提交时发生。最新OpenAPI已定义关系标识/版本、箱/车聚合版本及1000箱批次上限；直接关系的查询、候选、批量绑定、所选解绑及一键解绑均已接真实接口；一键解绑针对完整集合，不受所选批次上限影响。
- **外部系统编排**：成品发货、缴库申请各由一次业务提交触发完整处理，不要求App分别调用LES、MES、SAP、WMS。明确业务拒绝后可发起新的完整提交，不按上次进度接续；网络或异常回执未确认时，手动重试原请求标识及输入，不自动创建新业务意图。发货外部WMS清理失败不代表LES回滚，后台按原范围核查恢复，不由App重复重建或扩大删除。
- **前端本地操作**：清空页面、删除未提交记录、物料/箱码匹配已加载列表并勾选、三级级联切换与去重无需单独接口。候选位置层级可随扫描查询一次提供。
- **记录与错误**：业务接口应记录操作人、时间、终端/工位、对象、关系变更、结果和相关业务单号，并给出可直接展示的失败原因；不因关系清理删除追溯记录。本期不额外增加操作记录页面或查询接口。
- **本清单不增加业务范围**：不新增审批、离线补传、AGV 调度执行及库存入账接口。是否拆分箱/载具识别、明细查询、跨系统内部服务，由后端结合现有能力确定。
