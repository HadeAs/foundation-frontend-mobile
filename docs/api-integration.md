# 真实接口接入与联调

最后更新：2026-10-09。

## 接入范围

- 首页 16 个业务菜单调用 `nari-logistics.openapi.json`（修订 2026-10-09.2）中的 41 个业务接口。共享查询按场景复用，回库复用创建物流任务接口并传 `destinationMode=RETURN_LINE_SIDE`。
- 登录、退出、用户详情/部门、热更新参数及文件下载使用 `foundation-frontend-runtime.openapi.json` 中的接口。
- `apiTransport.ts` 始终调用 `uni.request`，不再读取 `VITE_API_MODE`，不提供本地业务数据、延时模拟、模拟错误或失败回退。已有环境文件中的该变量可以删除。
- 旧版库存查询、库房任务（含详情）、容器管理页面及路由、服务、专用组件/类型和测试已移除；扫描录入工具保留。
- 此次完成的是前端接入，不代表后端接口已部署或设备联调通过。文档仍保留部分设计提案标记，生产配置和权限需与后端核实。

## 地址与认证

- 测试环境：`http://192.168.0.171:18080`；生产地址仍为空，未配置时禁止登录。
- App 使用登录环境的基础地址，后续请求携带真实登录返回的 Bearer Token。
- H5 使用同源 `/api`。`npm run dev:h5` 启动的 Vite 代理转发至测试环境；生产 H5 需由 Web 服务配置 `/api` 反向代理。浏览器预览静态构建产物不会自动获得 Vite 开发代理。
- PDA 需可访问测试后端所在网络；接口不通时只展示真实错误，不使用演示数据补偿。
- 部门来自真实用户详情接口；查询失败或未分配时显示“未分配部门”。不要将历史登录会话里的演示部门当作最新查询结果，联调前重新登录。

## 业务提交及恢复

- 所有写操作由后端判断版本、关系、资格与权限。前端按文档提交请求 UUID 和版本，不在本地生成业务单号、预占或绑定关系。
- 保持现有页面的清空、错误提示、防重复点击及过期响应丢弃规则，不新增原型未确认的占用排队或位置绑定后去向弹窗。
- 取消任务与手动叫料的未知结果继续按原请求查询。原有 `foundation.cancellations.real.*`、`foundation.material-calls.real.*` 记录保持兼容，按账号/环境隔离；重启不得丢弃未确认请求或自动重发。
- 历史模拟业务记录不迁移到真实业务，旧 `.mock` 存储记录不会读取；不删除真实待确认记录。

## 热更新

- 登录后立即检查，随后按现有一分钟周期查询真实系统参数 `foundation.app.latest-version`、`foundation.app.wgt-file-id`。
- 符合更新条件后由用户确认下载，通过 `/api/v1/files/{id}/download` 获取 WGT；下载、安装仍仅在 App 环境执行。权限、版本及文件 ID 配置见 `wgt-update.md`。
- 不再使用固定空参数抑制更新，测试环境配置的真实新版本可能触发更新提示。

## 自动化验证与联调边界

```sh
npm test
npm run typecheck
npm run build:h5
npm run build:app
```

- `src/services/__tests__/fixtures/nariBackend.ts` 仅是回归测试的后端替身，由测试在 `uni.request` 注入；没有生产代码引用，不进入应用构建。它的示例编码不代表真实后端存在这些对象。
- 请求契约测试覆盖文档 41 个接口及共享用途、回库模式；请求层测试验证始终走网络、Bearer、H5/App 地址、失败无回退及旧页面无残留。
- 自动化测试不得直接提交真实装箱、卸载、物流、交通管制、SAP/WMS 操作。实际联调应使用专用测试账号、有效业务编码和可恢复数据，由业务人员确认执行范围。
- HTML 交互原型仍用于设计展示，不是实际应用，也不会调用真实接口。
