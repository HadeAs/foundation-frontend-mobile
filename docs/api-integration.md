## 接入范围

- 首页18个菜单及45项接口均使用真实请求，已逐菜单完成本地 `nari-logistics.openapi.json` 2026-10-12.1前端适配，18个菜单均已通过用户前端验收（最后菜单手动叫料于2026-10-13确认）。卸车保留完整库位装箱快照、所选关系原ID/版本及实际内容，可选物料展示字段不阻断查询；只有完整关联回执才清空，未知结果手动复用原UUID，不自动重发。料箱绑车/料箱解绑使用Direct摘要（名称必返，无实际内容/批次字段）；绑车校验原有/新增集合及更新版本，解绑核验所有未选关系及箱版本，一键解绑回执须为空。绑定页一键解绑成功使用新料车版本继续扫码，独立解绑页完整成功后清空；未知结果均保留原请求供手动重试。接收确认已补齐object及最新任务版本回执。直接关系接口不复用卸车库位关系；回库继续传 `destinationMode=RETURN_LINE_SIDE`。前端验收完成不代表后端已部署或PDA联调通过。
- 当前统一依据 `nari-logistics.openapi.json`（`x-design-revision=2026-10-19.1`）；登录、退出、用户详情/部门、热更新参数及文件下载已合并在该文件，旧独立基座文档不再作为入口。
- 本轮在原外部操作防重、接收清理任务刷新和交管版本刷新基础上，调整取消处理中/404防重语义及发货清理范围提示，不改变45项PDA接口路径/请求模型。前次18菜单验收仍是2026-10-12.1基线，不等于新版候选已联合验收；六项问题中1～5仍待后端补齐，第6项删除谓词已明确，详见[后端契约待补充清单](nari-logistics-backend-contract-questions.md)。
- `apiTransport.ts` 始终调用 `uni.request`，不再读取 `VITE_API_MODE`，不提供本地业务数据、延时模拟、模拟错误或失败回退。已有环境文件中的该变量可以删除。
- 旧版库存查询、库房任务（含详情）、容器管理页面及路由、服务、专用组件/类型和测试已移除；扫描录入工具保留。
- 此次完成的是前端接入，不代表后端接口已部署或设备联调通过。文档仍保留部分设计提案标记，生产配置和权限需与后端核实。

## 地址与认证

- 默认固定地址：`http://192.168.0.171:18080`，不再提供环境预设切换。登录页勾选“使用自定义环境地址”后使用设置弹框保存的IPv4地址（可带端口及HTTP/HTTPS协议）；省略协议补HTTP，启用却未有效配置时禁止登录。地址和开关缓存在设备本地，关闭开关不删除地址。
- App 使用登录环境的基础地址，后续请求携带真实登录返回的 Bearer Token。
- H5 默认服务器使用同源 `/api`。`npm run dev:h5` 启动的 Vite 代理转发至默认地址；生产 H5 需由 Web 服务配置 `/api` 反向代理。自定义地址使用绝对URL直连，后端需允许页面来源跨域，HTTPS页面不能直连HTTP混合内容。浏览器预览静态构建产物不会自动获得 Vite 开发代理。
- 登录成功后服务器地址固定在会话中；业务接口、退出登录、WGT参数查询及相对下载接口均使用该地址，修改登录设置不会改写现有会话。
- PDA 需可访问测试后端所在网络；接口不通时只展示真实错误，不使用演示数据补偿。
- 部门来自真实用户详情接口；查询失败或未分配时显示“未分配部门”。不要将历史登录会话里的演示部门当作最新查询结果，联调前重新登录。

## 业务提交及恢复

- 所有写操作由后端判断版本、关系、资格与权限。前端按文档提交请求 UUID 和版本，不在本地生成业务单号、预占或绑定关系。
- 两种绑箱的混料待确认不是写入成功；继续时原样回传服务端凭据及输入并生成新UUID。超时等未知结果仅手动按原UUID重试；409冲突丢弃旧凭据并要求重扫。一键解绑后重新查询箱状态，不根据0条板件关系判断物理空载。BindingLine批次必返，候选批次和名称可缺省。
- 快捷绑箱必须扫描实际代表板件码（33～128字符），提交该panelCode和后端查出的订单、数量；订单只读，不在前端解析码段。同BY_ORDER方式已有绑定可追加，BY_CODE方式须先整箱解绑再切换；代表码不作为数量行的逐件身份。混料继续时不读取已改变的表单值，使用原提交快照。
- 板件解绑查询完整LES关系与逐行批次，实际内容不由列表推断。所选整行提交原字符串关系ID/版本，最多1000条，全部解绑不提交items。完成回执校验UUID、箱码、新版本、关系条数及剩余件数后才清空；未知结果原UUID/内容手动重试，明确拒绝后新UUID，不自动重发。
- 装车只操作SLOT真实库位关系，由装车料箱查询/批量提交校验与DIRECT关系互斥，不自动解绑。容器摘要内容字段可缺省，缺省或UNKNOWN不视为空载。提交仅含配对箱/库位及各自版本和UUID；通用回执匹配请求与完整配对数量才清空，不推算最新容器版本。未知结果同配对手动复用UUID，明确拒绝或编辑配对后生成新UUID。
- 位置绑定按独立解绑资格和全部阻塞任务判断；有阻塞先确认取消，携带任务版本及位置/容器双方版本上下文。取消前保存原请求标识，按账号/环境隔离；ACCEPTED包含内部SENDING，显示处理中，不证明调度已受理，和UNKNOWN均只手动查询原请求、不重发取消。503/404保留原关联，不按FLOW错误文字解锁。最终取消后仍刷新库位、容器、阻塞及实物资格，再次确认解绑；占用对象变化必须清空重扫。完整绑定/解绑回执匹配原UUID及实际1条后才清空，未知操作同UUID/内容手动重试。
- 缴库申请按全对象版本提交，不发送物料选集或MES/SAP/WMS步骤参数；详情用途固定为WAREHOUSE_APPLICATION且不替换对象快照。完整回执关联原UUID、申请编号、SAP单号及WMS成功才清空。提交前按账号/环境持久化完整原请求；409/408/5xx及网络/回执异常均保留，手动原样重试（包括旧version），后端只按可信检查点续办，不重复申请SAP。409尚不能区分明确拒绝与部分成功，暂不释放为新UUID；初次其他明确4xx才结束请求。重进不自动提交，存储异常只允许重读。
- 2026-10-19.1明确无SAP/WMS效果的失败需核实失败及保护释放已持久化，才可刷新、新UUID；内部检查点不是公开字段。前端不解析MES_REJECTED等message状态，不自行决定哪个阶段续办。接收任务查询仅刷新版本/接收进度，不能证明原WMS清理回滚，即使新版本/已接收仍不得更换未决请求的UUID。
- 物料接收按冻结运输范围查询，扫箱确认该箱、扫车确认剩余箱；回执须包含最新任务版本及新增接收箱数，重扫仍先查新任务。WMS清理独立、不带备注；提交前持久化原UUID/任务/对象/版本，未决时锁定新操作，仅手动原样重试。清理成功/失败后立即按原任务及对象查最新版本，不推算版本、不改原未决请求；查询失败移除旧可写快照。affectedCount是完成清理箱数，非远端删行数；零匹配行可完成。503无法判别明确回滚与未知，暂不新UUID重删。远端按箱码及status=100、不带lCode，确认提示可能影响同箱其他申请，不能声称按任务隔离。
- 待接收清单沿用载具/位置精确条件、每页20条和后端排序；任务为运输查询投影，部分接收仍保留，完整范围完成后由后端退出。前端只读显示派生状态与箱数，不按资格自行筛选；文本任务ID、标准任务/容器版本及进度校验不通过时整页保留原数据供手动重试。可选位置不推断，隐藏停止事件与迟到响应，恢复时查第一页，不发接收/清理/物流写请求。
- 成品发货仍使用完整WMS内容及原扫描身份、实际容器/版本。503可能LES已重建；提交前持久化原UUID和完整原请求，清空/新扫码/隐藏不丢失。明确清理失败仅原请求旧version补清理，未知由后端阻止，App不重建、不自动重发。只有完整最终回执才清空并按后端标志询问物流创建。迟到可信结果可结算原本地记录，但不恢复页面或弹窗；账号/环境隔离，存储异常禁止覆盖。人工核查及解锁入口待后端补齐。
- 发货远端清理按箱码，不按状态或申请号隔离；对象卡明示可能影响同箱其他申请，不发送lCode等额外过滤。当前无自动过期不等于永久保存保证，回执保留/缺失/过期处理仍待补；不凭时长、404或新对象查询解锁未决请求。
- 发起物流任务保持后端解析的箱/车及品牌，不默认配置；固定GENERAL，完整三级候选与唯一推荐规则不变。实际内容独立展示，UNKNOWN/缺省不视为空载；起始位置使用查询值，不填入规划位置。指定/回库均校验原UUID、任务身份/标准版本、对象及非旧容器版本、品牌/类型、真实起止及必返运输状态/时间后才清空；完整任务的派送UNKNOWN仍代表任务已创建，不重复创建。未知请求同UUID/完整内容手动重试，明确拒绝或更换目标/模式后新意图。回库保留载具启用范围、后端目标分配，不传手选目标和发货关联；隐藏清空且不自动查询/重发。
- 保持现有页面的清空、错误提示、防重复点击及过期响应丢弃规则，不新增原型未确认的占用排队或位置绑定后去向弹窗。
- 取消任务列表校验完整身份/标准任务版本、固定GENERAL、容器/起止及标准运输状态，不根据状态在前端重筛；分页异常保留原页。普通取消只传任务版本与预先保存的UUID，不带解绑上下文；即时只认ACCEPTED/CANCELLED，查询再认FAILED/UNKNOWN，两者均关联原请求及有效处理时间。ACCEPTED统一显示处理中、不保证调度受理，含旧记录恢复；可见时3秒只读轮询，确认框/隐藏停止。未知及查询404保留原UUID，只手动查询，404不证明未发送/过期；FLOW 503当前无记录且无稳定标识，不能按message重新取消。结果原因不设额外长度限制，迟到回执只安全同步原关联及对应任务，不刷新/提示新视图。存储异常保留原记录并禁止新取消，账号/环境改变后旧视图不调用原任务接口。最终取消与实物结算、位置/装载解绑独立。
- 可取消清单当前返回全部未结算是后端待修缺陷，不是新需求；keyword当前匹配任务号/起止位置而非容器/AGV，排序也有偏差。前端不新增资格筛选、不重排、不改已确认搜索条件，交由后端统一筛选、分页及检索实现。
- 呼叫空载具只查目标位置的完整候选，默认响应首项且切换同步载具/版本。候选资格由后端提供，实际内容缺省/UNKNOWN不视为空载；可信当前位置可缺省，若返回须与该起点一致。提交核验原UUID、完整任务/标准版本、载具及非旧聚合版本、真实起止与状态/时间，完整任务UNKNOWN仍代表已创建；成功仅提示并清空。网络/408/5xx/异常回执的手动重试保留原UUID及完整输入，明确拒绝或确认更换起点/目标后新请求；弹窗禁止背景操作、隐藏清空且不自动恢复写入。
- 交通管制仍校验完整区域/版本、历史与分页；锁定/释放回执可能是历史重放，成功后无论有无筛选均重新查询第一页，下一操作必须使用新查询值。刷新失败保留列表并禁止操作，手动重试查询，不重复已成功写入。未知写入仍复用原区域/动作/版本/UUID，不自动重发；二次确认、固定状态按钮及隐藏只读恢复不变，不把控制释放当作车辆离开或任务取消。
- 缴库发起只查扫描码，精确匹配车码/起始位置恢复提交类型；位置关联料箱失败，固定GENERAL及唯一必返推荐，不截断候选/箱/物料。实际内容与零物料独立，可选名称/单位/文本批次不阻断，WAREHOUSE_LOGISTICS只读详情不改提交版本。提交仍仅原扫描身份、载具/版本、目标及UUID，不加品牌/类型/物料选集或重复申请SAP。完整关联任务/版本、品牌/类型、真实起止及状态/时间才清空；未知结果原UUID手动重试，明确拒绝或改目标/新扫描后新请求，隐藏不恢复写入。
- 手动叫料候选校验完整三级目标/运行版本、唯一箱/版本/数量及资格原因，起始位置摘要允许缺省层级；不新增订单主数据或生产计划依赖。编辑订单保留原清单，显式查询成功才替换；初次明确拒绝后保留位置/订单、自动刷新一次清单并清除勾选。完整回执关联原UUID/订单/目标/ISO时间及每箱唯一文本任务，支持包括CANCELLED在内六种简化派送状态；完整回执中的UNKNOWN/FAILED/CANCELLED不表示任务未创建，不重新创建或轮询派送。点击“重试原请求”复用原UUID及完整入参提交，不调用独立结果查询、不自动重发。原 `.real.*` 记录兼容旧位置上下文并按账号/环境隔离；无法读取/记录最终结果时保留原记录并禁止新提交，仅提供本地重读。隐藏不显示迟到页面结果，迟到写回仅更新原作用域记录；返回不自动提交、原请求仍运行时禁止并发重试，账号/环境改变后重新进入页面。
- 历史模拟业务记录不迁移到真实业务，旧 `.mock` 存储记录不会读取；不删除真实待确认记录。

## 热更新

- 登录后立即检查，随后按现有一分钟周期查询真实系统参数 `foundation.app.latest-version`、`foundation.app.wgt-file-id`。
- 符合更新条件后由用户确认下载，通过 `/api/v1/files/{id}/download` 获取 WGT；下载、安装仍仅在 App 环境执行。权限、版本及文件 ID 配置见 `wgt-update.md`。
- 不再使用固定空参数抑制更新，测试环境配置的真实新版本可能触发更新提示。
