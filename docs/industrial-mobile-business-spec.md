# 南瑞物流 App 业务功能 SPEC

> 状态：已确认基线（原型确认完成）  
> 版本：1.3.1\
> 最后更新：2026-09-07\
> 本文是当前业务实现与验收的主依据。早期 PRD、讨论稿或原型与本文冲突时，以本文及最新确认原型为准。

## 1. 业务目标与范围

App 面向车间、物流和库房员工，支持装箱、装载、位置绑定、接收、关系解除、发起物流任务与取消、空载具呼叫及交通管制。App 负责采集、展示、确认和提交；AGV 调度、设备通信、库存入账、异常恢复等后续流程由后端或设备系统处理。

本期不包含：AGV 执行过程、缴库申请后的上架执行过程、库存状态流转、审批与异常处置、容量/重量/体积限制、离线扫码与离线补传。

## 2. 通用业务规则

- 所有业务页使用统一扫码输入：支持 PDA 扫码、相机扫码和手动输入；进入页面不自动聚焦输入框。
- 扫码值先去首尾空格并统一规范化；重复扫码、编码不存在、状态不允许等错误由页面明确提示。
- 确认、绑定、装载、解绑、卸载、接收、呼叫等提交成功后清空当前页面，可立即开始下一次作业。
- 提交失败时保留页面数据，显示红色错误文字，用户可再次点击并发起新请求。
- 普通成功/失败提示采用导航栏下方浮层，不占固定提示区；浮层有浅色半透明背景、边框和阴影，不使用声音或震动。
- 会改变业务关系的批量操作应由后端原子提交，不允许部分成功后静默忽略失败。
- 后端记录操作类型、对象、操作人、时间、终端/工位、变更前后关系、结果及失败原因。
- 菜单入口全部开放，当前不做前端权限控制。

## 3. 登录、环境与个人信息

### 3.1 登录

- 使用真实接口 `POST /api/v1/auth/login` 完成认证。
- 登录成功后保存 Token 和用户信息并进入首页；后续受保护接口携带 Bearer Token。
- “记住账号”仅保存账号，不保存明文密码。
- 登录页底部显示当前环境文字，点击文字打开环境选择。

### 3.2 环境预设

- 测试环境：`http://192.168.0.171:18080`。
- 生产环境：地址留空，正式发布前配置。
- 切换环境后，所有接口与文件下载均使用该环境的基础地址。

### 3.3 个人信息

- 展示登录接口返回的用户 ID、登录账号、用户名称和所属部门等有效信息，不展示权限明细。
- 头像显示用户姓名的首个字符；英文字符转换为大写。
- 页面显示当前 App/WGT 版本号，并提供退出登录。

## 4. 板件扫码绑箱

1. 页面只有一个扫码输入框；首次扫码必须是箱码，并调用箱信息接口。
2. 后续扫码均按物料唯一码查询并加入“待绑定”列表；重复数据前端去重。
3. 若箱内已有 N 个物料，弹窗提示“当前箱子已绑定 N 个物料，是否需要一键解绑”。
   - 选择“是”：调用一键解绑接口；成功后保留当前箱信息，无需重新扫码。
   - 选择“否”：显示已绑定物料，标记为“已绑定”且不可删除。
4. 待绑定物料标记为“待绑定”，右上角删除图标仅删除本次待绑定记录。
5. 列表只要存在已绑定或待绑定物料，即可点击“获取拼板”。请求同时携带两类物料；返回结果去重后直接加入待绑定列表，不再二次选择。
6. “确认装箱”只提交待绑定物料。当前不限制同一订单，不存在尾单概念。
7. “清空页面”恢复首次扫描箱码状态。

## 5. 板件快捷绑箱

1. 首次扫描箱码并查询箱信息。
2. 若箱内已有物料，提示必须先一键解绑：
   - 确认：调用一键解绑，成功后保留箱信息。
   - 取消：本次箱码扫描无效，页面回到初始状态。
3. 有效箱信息存在后，可扫描物料唯一码，由后端返回订单号；也可手动输入订单号。
4. 用户填写数量后点击“确认装箱”；订单号和数量均为必填且数量必须大于 0。
5. 底部提供“清空页面”和“确认装箱”。

## 6. 装车

此功能建立“箱—载具库位”关系。

1. 单一输入框交替录入：先扫描载具库位号，再扫描箱码。
2. 扫描库位后显示一条配对卡片，包含载具库位号、载具编号和暂为空的箱子编号。
3. 扫描箱码后补全该卡片；下一次扫描开始下一组“库位—箱”配对。
4. 每条配对卡右上角提供删除图标。
5. 点击“确认装载”批量提交全部完整配对；同一箱同一时刻只能绑定一个载具库位。
6. “清空页面”删除全部未提交配对。

## 7. 位置绑定

1. 常规作业下提供“位置绑定”入口；单一输入框先扫描库位，后端返回库位信息及当前绑定容器。
2. 若已有绑定容器（载具或箱子），展示容器编号、类型和“已绑定”状态；禁止扫描新容器和提交新绑定。
3. 点击“解绑容器”后二次确认；后端解除库位与容器关系并保留历史记录。成功后按通用规则清空页面，重新扫描该库位可继续作业；失败保留数据并允许重试。
4. 仅当库位无绑定容器时，允许继续扫描载具或箱子，查询并展示容器信息，标记“待绑定”。
5. 点击“确认绑定”提交库位及容器编号、类型；后端再次校验库位占用状态，成功后清空页面并按业务规则触发后续流程。
6. “清空页面”只清除当前页面数据，不解除后端关系。系统自动带出的目标位置仍为只读。
7. 原型演示区提供“库位已绑载具”和“库位已绑箱子”按钮，点击重置并展示对应占用场景，可重复演示解绑。示例：`KW-BOUND-BOX` 已绑箱子，`KW-BOUND-CAR` 已绑载具，`KW-03-02` 初始为空；原型内绑定或解绑后重新扫描可查看变化。

## 8. 物料接收

- 支持扫描箱码或载具码；接口无任务数据时提示“当前箱子/载具无接收任务”。
- 扫描载具后展示载具内箱列表；点击箱信息块调用接口，并在弹窗中展示该箱物料明细。
- 点击“确认接收”即结束本次流程，不再引导进入卸车。
- 提供“清空 WMS 历史”，点击后调用后端清理接口。
- 底部三个按钮同排展示，顺序为“清空页面 / 清空 WMS 历史 / 确认接收”。

## 9. 板件解绑

1. 先扫描箱码，后端返回箱内全部已绑定物料。
2. 后续扫描物料唯一码；若与列表记录匹配，由前端自动勾选对应项。
3. 用户也可手动勾选多条；不提供“全选”按钮。
4. 底部提供“清空页面 / 全部解绑 / 解绑所选”。
5. 单项、部分和全部解绑均只解除关系，不删除物料、箱或历史记录。

## 10. 卸车

1. 先扫描载具码，后端返回载具全部库位及其中的箱子。
2. 后续扫描箱码；若与列表记录匹配，由前端自动勾选对应项。
3. 用户也可手动勾选多箱；不提供“全选”按钮。
4. 底部提供“清空页面 / 全部卸载 / 卸载所选”。
5. 操作仅解除“箱—载具库位”关系，保留历史记录。

## 11. 待接收物料清单

- 进入页面立即查询当前待接收物料清单。
- 列表展示任务号、载具号、库位号和创建时间。
- 查询条件为载具号和库位号。
- 滚动到底部自动加载下一页；刷新或变更查询条件后从第一页重新加载。
- 需要防止旧请求覆盖新查询结果，并对空数据、加载失败和重试给出明确状态。

## 12. 发起物流任务

1. 初始可扫描载具码或起始位置编码。
2. 后端识别关联载具/容器，返回其当前起始位置以及允许选择的目标位置集合；前端不自行推导可达范围或任务类型。
3. 目标位置采用“楼层 → 区域 → 库位名称”三级级联：
   - 首次打开不默认选中任何层级。
   - 切换楼层后清空区域和库位。
   - 切换区域后清空库位。
   - 三级完整选择后才能确认。
4. 已选位置统一显示为“楼层 / 区域 / 库位名称”，提交时使用对应库位编码。
5. 点击“确认创建”提交关联对象、起始位置和目标位置；成功提示任务编号并清空页面。
6. 不区分前端任务类型，不包含“未满载立即发送”。满载自动任务由后端创建，App 仅在相关查询中展示。

## 13. 呼叫空载具

1. 用户扫描目标位置，后端返回可选起始位置及各位置上的空载具；一个起始位置最多对应一个空载具。
2. 默认选中第一个起始位置及其空载具，用户可切换。
3. 起始位置使用与物流任务相同的三级级联和逐级清空规则。
4. 库位选择框只显示“楼层 / 区域 / 库位名称”；空载具编号在选择框外单独展示。
5. 点击“确认呼叫”提交最终起始位置、目标位置和空载具，由后端创建任务。
6. 成功后仅提示成功并清空页面；失败时保留页面供再次提交。

## 14. 取消物流任务

- 后端只返回当前允许取消的任务，前端不判断可取消条件，因此每条任务始终显示“取消任务”。
- 搜索条件为“容器码 / AGV 编号或名称”；不提供品牌和任务类型筛选。
- 卡片展示：任务编号、AGV 编号和名称（同一行）、关联容器、起始位置、目标位置、当前状态、发起方式和发起时间。
- 页面不展示任务类型，也不使用“A 点 / B 点”表述。
- 点击取消必须二次确认；后端返回成功、失败或不可取消原因。失败时任务保留在列表。

## 15. 交通管制

- 列表展示区域编号、区域名称、当前状态、最后操作人和操作时间。
- 本期状态仅有“空闲”和“占用”。空闲区域固定显示“锁定”，占用区域固定显示“释放”。
- 操作按钮位于卡片右侧，与左侧最后操作人、操作时间两行水平居中对齐，使用紧凑尺寸。
- 点击锁定或释放必须二次确认；成功后更新状态、操作人和操作时间。
- 当前不根据后端“是否允许操作”控制按钮，也不做按钮级权限控制。

## 16. WGT 热更新

- 登录成功后立即检查更新，此后每 60 秒检查一次；已有会话的 App-Plus 冷启动恢复检查。
- 读取系统参数：
  - `foundation.app.latest-version`：最新 WGT 版本。
  - `foundation.app.wgt-file-id`：最新 WGT 文件 ID。
- 当当前资源版本低于最新版本时，通过 `/api/v1/files/{id}/download` 下载、安装并提示重启。
- 更新接口携带当前环境 Token；离线、无更新或检查失败不得阻断业务。
- WGT 仅用于资源更新。原生插件、SDK、权限或原生配置变化必须发布新 APK/IPA。
- 发布时先上传并验证 WGT、更新文件 ID，最后更新版本号参数。

## 17. 验收与变更维护

- 每个功能至少验证：正常流程、无数据、重复扫码、接口失败、重复提交、清空重置和窄屏滚动。
- PDA 扫码必须在正式 APK/自定义基座和目标 Zebra 设备上验证；H5 内置浏览器不能代替原生广播验证。
- 新增或修改业务时，必须在同一变更中更新本文对应章节、接口契约、原型和回归用例。
- 删除或替换规则时直接修订正文，并在文末变更记录写明“新增 / 修改 / 废弃”，不得仅追加互相冲突的说明。


### 首页菜单分类

首页按以下分类及顺序展示三列宫格：

| 分类 | 菜单（按显示顺序） |
| --- | --- |
| 常规作业 | 板件扫码绑箱、板件快捷绑箱、板件解绑、装车、卸车、位置绑定、缴库申请 |
| 库房作业 | 物料接收、待接收物料清单、成品发货 |
| 物流作业 | 发起物流任务、取消物流任务、呼叫空载具、交通管制、缴库发起 |

首页直接展示作业分类，不显示问候语或用户名称。分类标题位于各组宫格上方。菜单名称与页面导航标题保持一致；“位置绑定”归入常规作业，菜单入口保持开放。

## 18. 成品发货（库房作业）

- 扫描位置、料车或料箱；位置按实际绑定对象识别为料车或料箱，无容器时提示并禁止提交。
- 展示全部关联物料，仅供查看，不支持部分勾选；无物料时禁止提交。
- 点击“成品发货”后由后端依次清空 LES 历史绑定、新增本次 LES 绑定、清空对应 WMS 绑定，再返回结果。仅清理当前绑定关系，保留发货及历史追溯记录。
- 料箱直接发货成功后提示结果并清空。料车发货成功后询问“是否创建物流任务”；选择是则携带料车进入现有发起物流任务页面，查询起始和可选目标位置，无需重新扫描；选择否则结束。
- 后续取消创建或任务创建失败不撤销已成功发货；任务创建失败保留任务页面供重试。

## 19. 缴库申请（常规作业）

- 扫描载具或箱子只查询并展示对象与全部关联物料，不立即申请；不支持部分选择，无物料时禁止提交。
- 点击“确认申请”后，后端按 MES 物料校验 → SAP 申请缴库单 → WMS 待上架清单新增的顺序执行；前一步成功后才可执行下一步。
- 成功浮层展示缴库单号并清空页面。失败保留页面及原因；再次点击发送新的完整提交请求，不按上次进度接续处理。

## 20. 缴库发起（物流作业）

- 扫描载具或位置，后端返回来源对象、明细、是否满足发起条件、推荐地点及可选地点集合。
- 是否需要先完成缴库申请由后端决定；条件不满足或无目标地点均作为扫描接口失败，直接通过统一失败浮层展示后端原因，不展示该次对象明细和目标地点。
- 默认选择推荐地点；多个地点可通过楼层、区域、库位三级级联切换，范围由后端返回。单个地点直接展示。
- 扫描失败后确认按钮禁用，允许重新扫码；不设置独立无目标/条件不满足状态页或“重新获取”按钮。
- 点击“确认发起”创建到库房的物流任务；成功浮层显示任务编号并清空页面。

### 三个新功能的公共规则

- 扫描新对象直接替换，清除原明细及目标地点，不二次确认。
- 载具/位置展示关联料箱清单，点击料箱查询物料并弹窗展示；直接扫描料箱时展示物料列表。
- 提交按钮直接执行，不二次确认；处理中禁止扫码与重复提交。失败保留数据，用户可重新发出请求。
- 后端记录操作人、时间、扫描对象、关联容器、结果及 LES、SAP、WMS 或物流任务返回的业务单号。
- 原型使用模拟接口演示；跨系统执行、真实数据和业务校验仍由后端实现。
