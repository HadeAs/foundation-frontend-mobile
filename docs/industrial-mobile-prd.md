# 工业移动端 PRD

## 问题陈述

仓储和现场作业人员需要在 Zebra PDA 等 Android 工业设备上完成基础移动端作业，包括登录、扫码录入、入库任务查询、库存查询和容器层级查询。系统需要适配 PDA 设备底层扫码能力，减少手工输入，提高任务和库存定位效率，并提供简洁稳定的移动端界面。

当前需求不是构建完整 WMS，而是提供一个可运行、可打包、可在 HBuilderX 和 Android PDA 上验证的 uni-app 简易工业系统原型。该原型需要覆盖核心页面、扫码输入抽象、PDA DataWedge 集成、分页数据模拟和基础测试。

## 解决方案

构建一个 Vue 3 + uni-app 移动端应用，面向工业 PDA 使用场景。

应用包含登录页和首页。首页底部使用图标标签栏切换“功能菜单”和“个人信息”。功能菜单采用三列宫格，进入扫描录入、入库任务、库存查询和容器管理。

扫码输入通过统一组件承载。相机扫码、手动输入确认、PDA DataWedge 广播扫码结果都统一进入同一输入与回调接口。PDA 监听逻辑独立为设备能力模块，不与输入框 UI 绑定，避免多个输入框重复注册监听。

入库任务和库存查询使用统一分页查询逻辑，支持初始加载、下拉刷新、触底加载下一页、输入/扫码筛选、请求竞态保护和 loading 状态。容器管理支持扫描或输入容器号，展示容器基本信息和可展开/收起的层级内容。

## 实现决策

- 应用采用 uni-app、Vue 3、Composition API 和 TypeScript。
- 应用使用自定义导航栏和页面级布局，不依赖原生导航栏。
- 登录采用本地模拟认证，用于原型验证。
- 首页包含底部页签，用于切换功能菜单和个人信息。
- 功能菜单采用三列图标宫格。
- 扫码输入实现为可复用 UI 组件，能力包括：
  - 双向绑定输入值；
  - 清除控件；
  - 可选相机扫码按钮；
  - 扫描事件回调；
  - 暴露外部设置扫描结果的方法。
- PDA 扫码集成实现为 composable，不放入扫码输入组件。
- PDA 扫码集成仅在页面显示时监听，并在页面隐藏或卸载时清理。
- PDA 扫码集成默认使用 Zebra DataWedge Profile `IndustrialMobile` 和已知广播 action，同时允许覆盖 Profile 和 action。
- PDA 扫码调试日志默认关闭，可通过选项开启。
- Zebra DataWedge Intent extras 通过扫码适配器统一归一化，支持常见 Zebra key 和动态 extras key。
- 扫描录入页支持键盘楔入模式，通过缓存按键直到 Enter 来解析扫描结果。
- 相机扫码使用 uni-app `scanCode`。
- 入库任务和库存查询共用一个分页查询模块，封装：
  - 首页加载；
  - 下一页加载；
  - 下拉刷新；
  - 关键字查询；
  - 防抖；
  - 最新数据去重合并；
  - 请求竞态保护。
- 入库任务筛选由模拟任务服务提供，查询范围覆盖全部任务数据。
- 库存查询筛选由模拟库存服务提供，支持条码、物料、容器和库位标识的模糊匹配。
- 容器管理页负责查询状态和基本信息展示。
- 容器层级渲染被拆分为独立树组件，展开/收起状态由树组件内部维护。
- 模拟服务代表后端契约，并通过延迟 Promise 触发 loading 状态。
- 构建目标保持为 HBuilderX/uni-app App Plus 输出。

## 测试决策

- 测试应关注外部行为和服务契约，不测试内部实现细节。
- 现有服务测试覆盖认证、扫码适配器解析、任务分页和筛选、库存分页和筛选、容器层级查询。
- 扫码适配器测试覆盖手动输入归一化、键盘楔入解析、相机扫码结果包装、DataWedge 固定 key 提取、动态 extras key 提取。
- 任务服务测试覆盖分页、第二页差异、按 ID 查询、按扫描任务单号筛选、最新任务获取。
- 库存服务测试覆盖分页、分页差异、模糊关键字搜索、最新库存获取。
- 容器服务测试覆盖容器详情、嵌套子容器、直接库存和未找到场景。
- 实现完成前必须通过 TypeScript 类型检查。
- 后续适合补充的组件测试：将 `ScanInput` 作为黑盒测试，覆盖输入更新、清除事件、扫描事件和 `setScanResult` 行为。
- 后续适合补充的 composable 测试：用假请求函数隔离验证分页行为，包括旧请求被忽略、筛选状态下刷新完成、下一页追加、最新数据去重合并。
- 硬件 DataWedge 行为需要在 Zebra PDA 上手工验证，因为真实广播桥接依赖 Android 运行时和 DataWedge 配置。

## 不在范围内

- 真实后端 API 集成。
- 真实用户认证和权限模型。
- 原型默认值之外的持久化本地存储。
- 创建、编辑或完成入库任务。
- 库存详情页。
- 容器绑定、解绑、移库等变更操作。
- 离线同步。
- 推送通知。
- 生产签名配置和正式发布管理。
- 完整 DataWedge Profile 管理界面。
- 支持当前 DataWedge 兼容流程之外的多 PDA 厂商。
- 完整视觉设计系统或组件库抽取。

## 补充说明

- 默认期望的 DataWedge Profile 名称为 `IndustrialMobile`。
- HBuilderX 标准基座测试时 Android 包名可能为 `io.dcloud.HBuilder`；正式 APK 应使用生产包名。
- 当前应用通过 uni-app App Plus 目标构建到 `dist/dev/app`，可在 HBuilderX 中打开并运行到设备或打包 APK。
- 当前验证命令为：
  - `npm run typecheck`
  - `npm test`
  - `npx uni -p app-plus`
- 当前环境没有 issue tracker 配置或可调用的 issue tracker 工具，因此 PRD 暂未发布到 issue tracker。
